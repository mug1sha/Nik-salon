# NIK Salon — Website demo

A responsive, premium family-salon website concept for NIK Salon, with two dedicated experiences:
- NIK Kids
- NIK Adults

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Build

```bash
npm run build
npm start
```

## Customize before publishing

1. Confirm all branch addresses, opening hours, services, prices and booking contacts with NIK.
2. Replace the curated remote photography with approved original NIK photos/videos.
3. Confirm permission and appropriate parental consent before publishing identifiable children's photos.
4. Replace the extracted logo crop in `public/images/nik-logo.png` with a clean, high-resolution official logo file if NIK can provide one.
5. Review the WhatsApp booking number and all social links in `src/app/page.tsx`.

## Brand direction

The supplied NIK artwork informed the visual palette:
- NIK green: `#08B957`
- NIK navy: `#092B3D`
- Sunshine yellow: `#F6C82D`
- White: `#FFFFFF`

The rainbow fan in the NIK logo is retained in the extracted logo image. The crop was taken from the supplied promotional artwork; a clean original logo asset would provide sharper results.
